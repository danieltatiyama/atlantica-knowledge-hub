# Stage 20.68 — Player-first Market price catalog (421 client references)

## Goal

The user reviewed the Stage 20.67 page in a desktop screenshot and requested a less technical, player-oriented default experience. The first view now prioritizes searchable items and prices instead of audit forms and 128 outstanding tasks already addressed by the player's earlier statement.

## Published routes

| Locale | Player-facing price catalog | Optional technical research workbench |
|---|---|---|
| English | `/tools/market-prices/` | `/tools/market-prices/research/` |
| Português | `/pt-br/tools/market-prices/` | `/pt-br/tools/market-prices/research/` |

The Tools hub links to the catalog. Both pages use existing `BaseLayout` language/theme controls. Existing research functionality (local observations, dates, import/export JSON, 128-item list) remains unchanged in a separate optional research route; old browser-local observation storage keys and validation contracts are preserved.

## What players see

- **421** named ItemIDs and **per-unit** gold reference prices from the client's general NPC trade catalog.
- **Five records** (four rings and Guardian Stone [I]) have an empty source category. They are displayed as **Uncategorized / Sem categoria** without inferring a category.
- Filters for name, category or ItemID, category selection, provenance class, and sorting by name, unit price ascending/descending, or ItemID.
- 50 results per page, next/previous navigation, total matching count and a mobile card layout.
- Direct links into the existing complete item database using `/items/database/?id=<ItemID>` and `/pt-br/items/database/?id=<ItemID>`.
- **293 historical crosschecks** from the November 14, 2025 Jana4U snapshot and **128 player-reported matches** from a single November 23, 2026 confirmation. These are **different kinds of evidence**, not independently verified live server Market listings. If the optional report file cannot be validated, those 128 rows show only a client reference label.
- A collapsed **About these prices and their evidence** section describes source limitations and links to the original research workspace; no large technical warning cards block the item table.

The public heading is **Market price catalog** rather than an unqualified "verified fixed prices" claim.

## Immutable sources and deterministic generation

The new public file `public/data/client-npc-trade-prices/catalog.json` is generated by `scripts/build-market-price-catalog.mjs`. It combines:

- Immutable client source archive `research/market-fixed-prices/client-npc-trade-2026-11-23.csv`.
- Historical mapping archive `research/market-fixed-prices/jana4u-2025-11-14-crosswalk.csv`.
- Already audited `public/data/client-npc-trade-prices/general.json` (421 prices) and `review-queue.json` (128 additional ItemIDs).

For all **421** entries the script verifies original name, category, ItemID, price and source CSV row, plus the exact separation into **293 + 128**. Public `catalog.json` contains `marketFixedPriceVerified:false`. It does not embed the separate player's report as if it were client evidence. The `player-report-2026-11-23.json` is loaded separately and checked against the original 128 candidate list.

The **231 housing entries**, including **227 identity collisions**, remain outside the general public catalog. The existence of 421 entries **does not prove** that the live Atlantica Global Market has only 421 fixed-price items or that every item is currently available.

## What was intentionally not changed

- No original `NPCTradeItem` prices, raw sources, housing entries or inferred names were modified.
- No price references are silently applied to the Crafting Calculator.
- No server-side editing API, account data or automated upload of personal evidence was introduced.
- The old review tool was not destroyed or emptied; it was moved behind a discoverable link.
