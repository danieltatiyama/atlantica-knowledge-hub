Nation Dungeons are activities that benefit from
coordination and planning between nation members.

This guide will eventually explain how to organize
runs, manage cooldowns, and coordinate schedules.

## Planning a Run

Before scheduling a dungeon, consider:

- The dungeon's cooldown.
- The server reset time.
- Member availability.
- Existing scheduled runs.
- The preferred timezone of participants.

## Shared Nation Calendar

A shared calendar can help members understand
when the next run is planned and which dungeons
are available.
